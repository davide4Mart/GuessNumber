# Number Guessing Game
A simple console-based game written in Python where the player has to guess a randomly generated number within a limited number of attempts.

## How to Play
1. Run the Python script:
   ```bash
   python guessing_game.py
Choose a difficulty level:
Level 1: Number between 0 and 50
Level 2: Number between 0 and 100
Level 3: Number between 0 and 1000

Try to guess the number. After each guess, the game will tell you if your guess is too low or too high.
You have a limited number of attempts (default: 10). After 5 attempts, the game gives a hint whether the number is even or odd.
The game ends when:
You guess the number (you earn points based on remaining attempts)
You run out of attempts (Game Over)
At the end of a game, you can choose to play again or exit.

Features
Multiple difficulty levels
Limited number of attempts
Hints after 5 incorrect guesses
Scoring based on remaining attempts
Modular code organized in functions

Requirements
Python 3.x
